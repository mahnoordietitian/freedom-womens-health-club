How to use your Admin Panel

Build everything from here. You do not need to manually create Firestore documents.

  1. Add your members.
  2. Create/edit your phases.
  3. Add weeks inside each phase.
  4. Add days inside each week.
  5. Add your daily content.
  6. Add lessons and assign them to days.
  7. Set the day on which content unlocks.
  8. Set member access until a specific week/day.
  9. Use Preview before saving.
  10. Add Lifetime Habits.
  11. Manage Community posts.
